# UI polish validation

The 2026-10-03 follow-up updates regression coverage for the neutral UI foundation,
compact Source/Flow layouts, Watch context menus and exact breakpoint interactions.
It supersedes the earlier compile-only checkpoint notes in the feature pages.
Validation used JDK 25 and the isolated `ui-polish-pr` worktree based on main
`7020ff7fdbf89adb81178f7058c455ac8d8433bc`.

## Results

- **50 JVM tests passed:** 40 in `clientTest`, 10 in `test`; zero failures, errors
  or skipped tests in their XML reports. The final check reran `clientTest`;
  `test` reused its passing result because its inputs had not changed.
- **10 selected native client GameTest classes passed:** nine together, followed
  by the focused `DebuggerBreakpointUiGameTest` after updating its removed
  list/Undo expectations. No production code changed between those native runs.
- `compileClientJava`, `processResources` and `git diff --check` passed.

`DebuggerBreakpointUiGameTest` retains real server Save/Delete acknowledgements,
checks return to the same editor and cursor, preserves the separate whole-command
definition, and recreates the deleted exact stage through native keyboard input.
The navigation list assertions check both saved destinations remain present and
unavailable rows cannot send hidden edits.

The new `DebuggerNavigationTest` replaces widget instances during pending edits
and checks explicit Tab/click navigation wins over later acknowledgement or
rejection. `FlowBreakpointInteractionGameTest` drives actual screen events for
unset run/function markers, visual Tab order, wrapped-row reveal, pending focus,
direct exact-target editors, cancel without mutation and list navigation.

Source checks retain glyph/edge pixel comparisons for the authoritative amber
stop and require manual code selection to remain neutral. Marker visibility checks
use the shared neutral color, including modal dimming. Compact Watch checks use
row menus and the full right-aligned value hit area in English/Korean fixtures.

  --tests '*BreakpointTargetPolicyTest' --tests '*ClientBreakpointStateTest' \

  --tests '*SourceInteractionTest' --tests '*DebuggerLayoutTest' \
